# SKZOO House 🏠💜

Protótipo visual interativo do SKZOO House, pensado para jogar no celular na horizontal.

## O que já existe neste primeiro protótipo

- Interface em formato paisagem, com identidade roxa, azul e neon.
- Mapa para alternar entre sala, quartos, cozinha, banheiro, quintal e sala de jogos.
- Cenário estilizado com móveis e iluminação ilustrativos.
- Seleção dos oito SKZOO por nomes e mascotes provisórios.
- Controles de interação demonstrativos: oi, brincar, descansar e dançar.
- Arrastar personagens na cena e controles de aproximação/afastamento da câmera.
- HTML, CSS e JavaScript em um único arquivo, sem bibliotecas externas.

## Importante

Esta é a **primeira versão de protótipo**, não o jogo 3D final. Os emojis são placeholders para testar a interface e os controles. Os modelos 3D reconhecíveis dos SKZOO, animações reais, colisões com móveis, roupas equipáveis, salvamento e funcionamento offline serão desenvolvidos e testados em etapas futuras.

A imagem-conceito criada durante o planejamento serve como referência artística; não é um conjunto de modelos ou cenários prontos para o jogo.

## Como testar

Abra `index.html` em um navegador moderno. No computador, também é possível testar a seleção e o arraste com o mouse. A interface é adaptável, mas foi pensada para a tela do celular na horizontal.
